Free and open source

Put take-home pay on every salary

Candidates want to know what a salary really pays. One script tag shows the after-tax figure next to any salary on your page, using the same open-source engine as this site.

1. Badges for job ads

Add data-openpaye-net to any element. Ranges work.
Senior Nurse, Cork€45,000 a year Software Engineer, Dublin€65,000–€80,000 
<script src="https://openpaye.ie/widget.js" defer></script>

<p>Salary: €45,000 <span data-openpaye-net="45000"></span></p>
<p>Salary: €40,000–€50,000 <span data-openpaye-net="40000-50000"></span></p>

2. Full calculator

An auto-sizing calculator card. Follows the visitor's light/dark setting.
<script src="https://openpaye.ie/widget.js" defer></script>

<div data-openpaye-calculator data-salary="45000" data-theme="auto"></div>

No script? Use a plain iframe: <iframe src="https://openpaye.ie/embed.html?salary=45000" title="Take-home pay calculator" style="width:100%;height:460px;border:0"></iframe>

Options

AttributeValuesWhat it does
data-openpaye-net45000 or 40000-50000Salary (or range) to convert
data-periodyear · month · week · hourWhat the salary figure is per (default year)
data-showmonth · year · weekWhich take-home figure to show (default month)
data-year2025 · 2026 · 2027Tax year (default 2026)
data-statussingle · singleParent · marriedOne · marriedTwoTax status (default single)
data-formatbadge · textLinked badge, or plain text
data-themeauto · light · darkCalculator theme
data-seedshamrock · atlantic · heather · amber · fuchsiaCalculator colour

JavaScript and JSON API

const r = OpenPAYE.calculate({ salary: 45000, year: 2027, status: 'single' });
// → { net, netMonthly, incomeTax, usc, prsi, effectiveRate, … }
GET https://api.openpaye.ie/v1/calculate?salary=45000&year=2027
GET https://api.openpaye.ie/v1/calculate?net=3000&period=month
GET https://api.openpaye.ie/v1/employer?salary=45000

The API is an open-source Cloudflare Worker in the repo's api/ folder. Deploy your own for free.

Free for everyone

The widget and API are free for any site, commercial or not, under the MIT licence. Keep the small "Full breakdown" link if you like it, or hide it with data-attribution="0". You can also host widget.js and embed.html yourself.

Keeping OpenPAYE free

No ads, no tracking, no sign-up. This is a passion project! However, hosting and upkeep cost money, so if this helped you, please consider buying me a coffee :)
